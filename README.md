# 📊 Power BI Sales Analysis Dashboard | End-to-End Data Analytics Project

## 📌 Project Overview

This project focuses on building an interactive Sales Analysis Dashboard using Microsoft Power BI. It covers the complete data analytics workflow, starting from understanding raw data and building a data model to creating DAX calculations and designing an interactive dashboard.

The objective is to analyze sales performance, track business KPIs, compare performance across different time periods, and generate meaningful insights to support business decision-making.

## 🎯 Project Objectives

- Understand and prepare the source dataset for analysis.
- Create a custom Calendar Table using DAX.
- Establish relationships between multiple tables.
- Develop a structured data model.
- Create calculated measures using DAX.
- Perform time-based sales analysis using MTD, QTD, and YTD.
- Compare current sales performance with the previous year.
- Build an interactive and professional Power BI dashboard.
- Publish the report using Power BI Service.

## 🔄 1. Data Understanding & Preparation

## 📅 2. Custom Calendar Table

Created a dedicated Calendar Table using DAX to enable accurate time-based analysis.

The Calendar Table supports:
- Year-wise analysis
- Quarter-wise analysis
- Month-wise analysis
- Date-based filtering
- Time intelligence calculations

This helps analyze business performance across different periods.

## 🧩 3. Data Modeling & Relationships

Designed the data model by connecting relevant tables through common key columns.

Key activities:
- Created relationships between fact and dimension tables.
- Configured relationship cardinality.
- Reviewed relationships in Model View.
- Established the Calendar Table relationship for time-based analysis.
- Organized the model for accurate filtering and reporting.

## 📐 4. DAX Calculations & Measures

Used Data Analysis Expressions (DAX) to create measures for business performance analysis.

The project covers:

- Basic DAX calculations
- Aggregation functions
- Calculated measures
- Time intelligence functions
- Year-over-year comparisons

### Time Intelligence Functions

| Function | Purpose |
|---|---|
| MTD | Month-to-Date analysis |
| QTD | Quarter-to-Date analysis |
| YTD | Year-to-Date analysis |
| SAMEPERIODLASTYEAR | Compares current performance with the same period in the previous year |

These calculations help understand sales trends and business growth over time.

## 📊 5. Dashboard Development & Analysis

Developed an interactive Power BI dashboard to present business performance through visualizations and analytical KPIs.

### Dashboard Analysis

The report is designed to help users understand:

- **Sales Performance:** Monitor overall sales performance through key metrics.
- **Time-Based Trends:** Analyze performance across months, quarters, and years.
- **Business Performance:** Evaluate important business metrics using DAX measures.
- **Period Comparison:** Compare current-year performance against the previous year.
